  <p style="margin:0 0 15px 0;line-height:1.6;font-size:16px">
      
  本项目用到的Ai-WV01-32S不采用默认附件，而是安信可开源团队开发的 UART-MCP 固件（固件地址看文本以下内容），**焊好的第一步就是烧录 UART-MCP 固件**，否则无法控制。<br />
   安信可为UART-MCP开发了一套专门的适配库：**emMCP**。只需要非常见到的移植，就能使用。因此 **天空星**只需要关注OLED显示和外设驱动的控制即可。
